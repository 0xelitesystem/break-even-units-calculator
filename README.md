# Break-Even Units Calculator

Your break-even point is the number of units where total revenue equals total cost: fixed costs divided by the contribution margin per unit, which is price minus variable cost per unit. This tool computes it and plots the revenue and cost lines so you can see where they cross.

**Live demo:** https://0xelitesystem.github.io/break-even-units-calculator/

## What it does

Enter fixed costs, price per unit, and variable cost per unit. The tool returns the contribution margin per unit and as a percent, the break-even point in units, and the revenue at break-even. It plots the revenue line and the total cost line on graph paper and marks the crossing point.

If price does not exceed variable cost, there is no break-even point, because each unit loses money. The tool says so plainly rather than returning a misleading number.

## Aesthetic
